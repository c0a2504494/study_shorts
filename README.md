# Study Shorts

Google スプレッドシートに保存した学習カードを、スマートフォンでショート動画のように連続表示する Google Apps Script（GAS）製の学習アプリです。

## 構成

- `Code.gs`: スプレッドシートの読み書き、学習記録、画像URL処理、Web API処理
- `Index.html`: 学習画面、操作UI、クライアント側ロジック、スタイル

## 主な機能

- シートごとの学習カード読み込み
- 問題・回答・補足コメントの表示
- 問題面と回答面の切り替え
- 学習回数・ランク・連続学習日数の記録
- 背景画像、問題画像、回答画像の表示
- Google Driveフォルダ内画像との同期
- iOSショートカット等からのカード追加

## スプレッドシートの基本列

学習カードは原則として次の列を使用します。

| 列 | 内容 |
| --- | --- |
| A | 問題文、または問題画像への参照 |
| B | 回答文、または回答画像への参照 |
| C | 学習回数・再出題制御用の値 |
| D | 学習ランク |
| E〜G | 補足コメント |

画像・背景・統計用の列やセルも使用するため、既存シートの列位置は不用意に変更しないでください。

## 導入方法

1. Google スプレッドシートを作成します。
2. スプレッドシートから「拡張機能」→「Apps Script」を開きます。
3. `Code.gs` と `Index.html` の内容を同名ファイルへ配置します。
4. 必要に応じて `authorizeDriveAccess()` を実行し、スプレッドシートとGoogle Driveへの権限を許可します。
5. Apps Scriptの「デプロイ」からウェブアプリとして公開します。
6. 実行ユーザーとアクセス範囲は、利用環境に合わせて最小限に設定します。

## 開発時の注意

- `main` に直接コミットせず、作業ブランチを作成してください。
- シートの列番号や設定セルを変更すると、既存データとの互換性に影響します。
- GAS固有のサービス（`SpreadsheetApp`、`DriveApp`、`LockService` など）は通常のブラウザJavaScript環境では実行できません。
- 変更後は、問題表示、回答表示、スワイプ操作、ランク更新、学習回数更新、画像表示を実際のGAS環境で確認してください。
- Driveやスプレッドシートの権限を必要以上に広げないでください。
