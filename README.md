# Study Shorts

Google スプレッドシートに保存した学習カードを、スマートフォンでショート動画のように連続表示する Google Apps Script（GAS）製の学習アプリです。

## 構成

- `Code.gs`: スプレッドシートの読み書き、学習記録、画像URL処理、Web API処理
- `AppConfig.gs`: 公開アプリ向けの名称・バージョン・起動データ
- `Landing.gs`: 起動画面と既存アプリ画面を結合する処理
- `Index.html`: 起動画面、Books選択、起動処理
- `App.html`: 学習画面、操作UI、クライアント側ロジック、スタイル
- `appsscript.json`: Apps Scriptランタイム設定

## 主な機能

- シートごとの学習カード読み込み
- 問題・回答・補足コメントの表示
- 問題面と回答面の切り替え
- 学習回数・ランク・連続学習日数の記録
- 背景画像、問題画像、回答画像の表示
- Google Driveフォルダ内画像との同期
- iOSショートカット等からのカード追加

## スプレッドシートの基本列

| 列 | 内容 |
| --- | --- |
| A | 問題文、または問題画像への参照 |
| B | 回答文、または回答画像への参照 |
| C | 学習回数・再出題制御用の値 |
| D | 学習ランク |
| E〜G | 補足コメント |

画像・背景・統計用の列やセルも使用するため、既存シートの列位置は不用意に変更しないでください。

## 導入方法

1. Google スプレッドシートを作成します。
2. スプレッドシートから「拡張機能」→「Apps Script」を開きます。
3. このリポジトリの `.gs`、`.html`、`appsscript.json` をApps Scriptプロジェクトへ同期します。
4. 必要に応じて `authorizeDriveAccess()` を実行し、権限を許可します。
5. Apps Scriptの「デプロイ」からウェブアプリとして公開します。
6. 実行ユーザーとアクセス範囲は、利用環境に合わせて最小限に設定します。

## モバイル公開へ向けた方針

現在のGAS版はプロトタイプ兼バックエンドとして利用できます。App Store・Google Playで一般公開する際は、画面とデータ処理を段階的に分離します。

1. **Webアプリ基盤の安定化**: バージョン管理、アクセシビリティ、エラー再試行、テストを整備
2. **API境界の明確化**: `getAppBootstrap()`のようなバージョン付きレスポンスへ統一
3. **認証とユーザーデータ分離**: 個人ごとの学習データを安全に保存できる構成へ変更
4. **ネイティブアプリ化**: FlutterまたはCapacitor等でiOS・Androidクライアントを作成
5. **ストア公開準備**: プライバシーポリシー、利用規約、サポート窓口、アプリアイコン、スクリーンショットを用意

## 今回整備した公開向け基盤

- アプリ名・バージョン・起動レスポンスを`AppConfig.gs`へ集約
- Books取得失敗時のRetry操作を追加
- Startの多重実行を防止
- キーボードフォーカス表示と動き軽減設定に対応
- モバイル向けテーマカラー、電話番号自動認識抑止などのメタ情報を追加
- Apps ScriptのV8ランタイムと例外ログ設定を明示

## 開発時の注意

- `main` に直接コミットせず、作業ブランチを作成してください。
- シートの列番号や設定セルを変更すると、既存データとの互換性に影響します。
- GAS固有のサービスは通常のブラウザJavaScript環境では実行できません。
- 変更後は、Books取得、Start、問題表示、回答表示、スワイプ、ランク更新、画像表示を実際のGAS環境で確認してください。
- Driveやスプレッドシートの権限を必要以上に広げないでください。

## 残っている重要課題

- 自動テストとLint設定
- 個人アカウント・認証・データ分離
- APIの認可、レート制限、入力検証
- プライバシーポリシーと利用規約
- オフライン対応とデータ同期
- `App.html`と`Code.gs`の機能単位分割
